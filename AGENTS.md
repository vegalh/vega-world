# Repository Guidance

- This repository is a static personal website published with GitHub Pages. Keep changes compatible with direct static hosting; do not introduce a build step or backend unless the requirements change.
- `index.html` is the homepage and currently contains the page structure, styles, and content. Keep edits focused and preserve its existing visual language unless a redesign is requested.
- Keep the homepage responsive and accessible. Use semantic HTML, descriptive link text, and meaningful alternative text for informative images.
- Keep local assets referenced with repository-relative paths so they work when deployed under the repository's GitHub Pages URL.
- Update `PRD.md` when the product's purpose, audience, or requirements materially change.
- Before finishing, check that changed links and asset paths are valid and that the page can still be served as static files.
